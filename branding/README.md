# Branding assets

Put your own logo files here and copy them to the branding folder referenced in
`nginx/vhost_nginx.branding.conf`:

| File                | Used for                          |
|---------------------|-----------------------------------|
| `my-logo.svg`       | Logo on light backgrounds         |
| `my-logo-white.svg` | Logo on dark backgrounds / top-left |
| `my-icon.svg`       | Browser favicon                   |

No logos are shipped with this repository.
